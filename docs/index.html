Flop Launcher

Il launcher per Minecraft Java semplice e curato: istanze separate, mod con un clic e Java che si installa da solo.

Scarica per Windows

Gratuito · Windows 10 e 11 (64 bit) · serve un account con Minecraft Java Edition

Istanze separate

Ogni istanza ha le sue mod, i suoi mondi e le sue impostazioni, senza mescolare niente.

Mod con un clic

Cerca su Modrinth e installa: le dipendenze, come Fabric API, arrivano da sole.

Java automatico

Nessuna installazione da fare: il launcher scarica la versione di Java giusta per ogni Minecraft.

Accesso Microsoft

Accedi una volta sola: la sessione resta salvata in modo cifrato sul tuo computer.

Come installarlo

  1. Scarica il file Flop-Launcher-Setup.exe e aprilo.
  2. Se Windows mostra “Windows ha protetto il PC”, è normale per un programma nuovo e non firmato: clicca Maggiori informazioni, poi Esegui comunque.
  3. Segui l’installazione e apri Flop Launcher dal Desktop.
  4. Accedi con Microsoft, crea un’istanza e premi Gioca. Al primo avvio scarica da solo Java e Minecraft: ci vuole qualche minuto.
